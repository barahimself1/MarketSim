# Data provenance and schemas

Bundled source: deterministic synthetic generator, seed 42, 500 instructions, SIM-USD, 100 ms event spacing. Generated by MarketSim; redistribution is permitted with the repository's MIT license. No historical market performance is implied.

| Entity | Fields / semantics |
| --- | --- |
| MarketEvent | sequence integer; timestamp_ms integer; type LIMIT/MARKET/CANCEL; order_id string; side BUY/SELL; quantity integer lots; price integer cents or null |
| Order | order_id, side, quantity, remaining, price, arrival sequence, state |
| Trade / Execution | trade_id, sequence, maker, taker, aggressor side, integer price and quantity |
| PriceLevel | price, aggregated remaining quantity, resting order count |
| Snapshot | sequence, bids, asks, mid, spread, microprice, top-ten imbalance |
| ParentOrder parameters | side, quantity, start event, duration events, POV fraction, fee bps, prior volume profile |
| ChildOrder | order_id, event index, quantity, optional passive price |
| TCAResult | fills, completion, average price, arrival, slippage, filled cost, fees, opportunity, decomposition |
| Experiment | configuration, seed range, timestamp, code version, results, SIMULATION ONLY status |

`marketsim.data.load(path)` accepts canonical JSONL and reconstructs the book to validate instruction semantics. It is a small-sample loader that materializes the stream; it is not advertised as an out-of-core historical pipeline. Replay itself is deterministic given validated instructions. The browser currently selects generated sessions only.

Historical adapters must preserve sequence order, handle gaps, distinguish order IDs from aggregate price levels, define cancellation semantics, and document distribution rights. Coinbase's public feed documentation describes snapshot/update feeds; aggregate depth updates do not establish order-level FIFO position. Reference: https://help.coinbase.com/en/developer-platform/websocket-feeds/exchange

No external data was downloaded or repackaged for this build. Do not fabricate order identities from aggregated size changes to claim exact historical queue reconstruction.
